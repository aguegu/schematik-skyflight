Keep the sensor still for 2 seconds at boot. Uno / classic Nano also supported on A4/A5; see README for level-shifter guidance. This is arcade flight: altitude is simulated, not measured by the MPU6050.

Click Connect MPU6050, choose the board, then use Controller → Zero current tilt. Mounting different? Swap or invert axes in Controller.
